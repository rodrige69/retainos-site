# RetainOS website (retainos.co)

Generated by `build.py` in English and Spanish. Edit and rebuild:

| File | What it holds |
|---|---|
| `build.py` | OFFER (spots, dates, contract), REWARDS wording, every shared section and the FAQs |
| `verticals.py` | One block per industry: headline, pain point, sample message, perk, reminder timing, mode |
| `style.css` | Look and layout |

Run `python3 build.py` (needs `pip install segno` for the sample QR code). Output goes to `site/`.

## What gets built
- **Homepage:** `/` and `/es`
- **20 industry pages**, English at `/<slug>` and Spanish at `/es/<slug_es>` (slugs in `verticals.py`). Modes:
  - `full`: loyalty and referral rewards
  - `family`: rewards go to parents (kids' activities, daycares)
  - `retail`: front-store purchases only (pharmacies)
  - `care`: booking, reminders and reviews, with rewards off (med spas, wellness centers)
- **Reward details and terms:** `/rewards` and `/es/premios`
- **Hidden $0-setup promo pages:** `/go/salons`, `/go/barbershops`, `/go/nail-lash` (add `?lang=es` for Spanish). Hidden from Google and never linked.
- `sitemap.xml` and `robots.txt`

To add an industry, copy a block in `verticals.py`, edit it, and rebuild. It appears on the homepage and in the footer automatically.

## Before launch
1. Fill in `OFFER` in build.py.
2. Confirm with the rewards partner: destination list, all-inclusive options, and the single fee example in `REWARDS`.
3. Replace placeholders in the pages: `<!-- VOTEL FORM -->` (set its redirect to the 15-minute kickoff calendar), `<!-- VIDEO -->`, and the privacy and terms links in the footer.

## Publish (GitHub → Vercel)
1. GitHub repo → **Add file → Upload files** → drag in this folder → commit.
2. Vercel → **Add New → Project** → pick the repo → set **Root Directory** to `site` → deploy.
3. Every commit publishes automatically. GitHub history is your backup.
4. Vercel → Project → Settings → Domains → add retainos.co when ready.
